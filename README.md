# Анализ рынка строительства жилых и нежилых зданий (ОКВЭД 41.20)

Анализ перспективности отрасли строительства на основе данных Единого реестра МСП ФНС
и финансовой отчётности компаний (bo.nalog.gov.ru).

## Задача

Собрать датасет малых и средних строительных компаний, спарсить их финансовую отчётность,
рассчитать динамику EBITDA и рост чистой прибыли по годам, визуализировать распределение
и географию топ-компаний по выручке.

## Данные

- Единый реестр субъектов МСП (ФНС России) — исходный список компаний
- Финансовая отчётность компаний с bo.nalog.gov.ru — получена парсингом (выручка,
  чистая прибыль, проценты к уплате)

## Методология

1. Фильтрация реестра: юридические лица, категории «Малое предприятие» и «Среднее
   предприятие», ОКВЭД 41.20 (строительство жилых и нежилых зданий)
2. Случайная выборка 500 компаний (`random_state` зафиксирован для воспроизводимости),
   парсинг финансовой отчётности через API bo.nalog.gov.ru
3. Расчёт упрощённой EBITDA по годам (чистая прибыль + проценты к уплате — без
   амортизации, которой нет в доступных данных формы 2), анализ доли прибыльных компаний
4. Расчёт распределения роста чистой прибыли компаний за 2021–2024 годы
5. Геовизуализация топ-100 компаний по выручке (geopandas, координаты — по региону
   регистрации со случайным разбросом)

## Основные выводы

Медианная EBITDA стабильно росла с 2021 по 2024 год (с 2594 до 3490 тыс. руб.), однако
доля компаний с положительной EBITDA не показывает такого же роста, держась нестабильно
в диапазоне 79–82%. Медианный рост чистой прибыли за тот же период составил -8% —
типичная компания практически не изменилась, при этом 30% компаний показали рост более
чем в 2 раза, а 14% ушли в глубокий убыток, что говорит о высокой волатильности отрасли
на уровне отдельных компаний. На карте видна выраженная концентрация крупнейших компаний
вокруг Москвы и Санкт-Петербурга.

Полный анализ, графики и обоснование допущений — в `analysis.ipynb`.

## Структура репозитория

- `analysis.ipynb` — основной ноутбук с полным анализом
- `financials.csv` — собранные финансовые данные по компаниям
- `ebitda_dynamics.png` — график динамики EBITDA
- `growth_histogram.png` — гистограмма роста чистой прибыли
- `map_top100.png` — карта топ-100 компаний по выручке

## Технологии

Python · pandas · requests · matplotlib · geopandas · geopy

## Ограничения

- EBITDA рассчитана упрощённо (без учёта амортизации)
- Данные за 2025 год неполны из-за задержки подачи отчётности компаниями
- Координаты на карте — по региону регистрации, а не по точному юридическому адресу
